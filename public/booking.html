How an empty leg works

A jet flies a booked charter from Mumbai to Delhi. If the operator needs it back in Mumbai, the return can become an empty leg. The operator sets the total price, then JetRelay reviews the aircraft and the original charter before publishing it.

The journey can change if the original charter changes. Read the operator’s terms before holding the aircraft. No fixed discount is guaranteed.
